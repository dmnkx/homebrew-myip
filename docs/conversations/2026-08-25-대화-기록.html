수행한 작업:

  • Formula/myip.rb — 플랫폼별 tar.gz URL, bin.install "myip"만. depends_on "rust" 없음.
  • 릴리스 CI가 macOS arm/intel, Linux arm/intel에서 바이너리를 빌드해 올리고 checksum으로 Formula를 갱신.
  • PR CI의 brew install --HEAD 제거 (사용자 PC에서 컴파일·CLT를 유발하지 않음).
  • scripts/package-binary.sh, scripts/generate-formula.py
